# Fast React Pizza

A responsive pizza-ordering web app where customers can browse the menu, build a cart, place an order, and check its status.

## Features

- Browse the pizza menu and view item details.
- Add pizzas to your cart and adjust quantities.
- Place an order with customer and delivery information.
- Optionally use your device location to suggest a delivery address.
- Look up an order by its ID, see its estimated delivery time, and add priority delivery.

## Tech stack

- **React 18** with **Vite**
- **React Router** for routing, data loading, and form actions
- **Redux Toolkit** and **React Redux** for cart and user state
- **Tailwind CSS** for styling
- **Fast React Pizza API** for menu and order data
- **BigDataCloud reverse geocoding API** for location-based address lookup
